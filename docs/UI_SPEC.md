## Сетка и размеры (100%, умножать на DPI/96)
- Базовый шаг 4px; отступы 8/12/16/20.
- Заголовок окна 32, меню 28 (системные).
- Сайдбар 248 шир., padding 16/12; карточка диска: padding 10/12/10/16, радиус 6, иконка 32×32 r6, акцентная полоса 3×(h−24) r2 на x=5, шаг 6.
- Контент: padding 16/20, вертикальный gap 12.
- Кнопки: h30, padding 0/12, r5, рамка 1px, gap 6; «Извлечь» disabled = 45% альфа (на GDI: TEXT_FAINT + BORDER).
- Блок вердикта: r8, рамка 1px, левая полоса 4px цвета статуса; глиф-круг 28 (фон = pill bg); правая колонка 290 шир. с разделителем 1px: «Диск о себе» (самоотчёт SMART) vs «Наша оценка», ниже Наработка (только годы) и Включений.
- Оси: 5 равных плиток, gap 8, r8, padding 10/12, точка 8×8.
- Таблица: r8, шапка 30, строка 26, разделитель 1px BORDER, зебра; проблемная строка = ROW_HL + левая полоса 3px цвета статуса; колонка «Статус» 170.
- Пилюля: h20, r10, padding 0/8, gap глиф-текст 5. Ширина = DrawText(DT_CALCRECT)+16.

## Реализация (ui/v2-design)

- Палитры `kPalLight` / `kPalDark` в `src/mainwnd.cpp`, макросы `CLR_*` в `mainwnd.h` указывают на `g_Pal`.
- Тема: Вид → Тема (как в системе / светлая / тёмная), хранится в `HKCU\\Software\\chuikoff\\DriveMonitor\\UiTheme` (0/1/2). По умолчанию следует `AppsUseLightTheme`, реагирует на `WM_SETTINGCHANGE` `ImmersiveColorSet`.
- Отладочные флаги: `--demo` (три фикстуры дисков, без обращения к устройствам; вердикты считает настоящий движок), `--theme=light|dark` (только на этот запуск).
- Всё рисуется GDI с двойной буферизацией: главное окно (`PaintMainV2`), блок оценки и оси (`PaintDashboard`), карточки дисков, шапка таблицы (сабкласс), строки таблицы (custom draw).
